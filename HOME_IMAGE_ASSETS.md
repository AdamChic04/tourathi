# TouRathi Home Images — Offline Demo

These four bundled JPEGs were AI-generated as visual mockups inspired by Petra, Jerash, Wadi Rum, and the Dead Sea. They are **not documentary photographs of the actual sites**.

Paths:
- assets/images/home/petra.jpg
- assets/images/home/jerash.jpg
- assets/images/home/wadi_rum.jpg
- assets/images/home/dead_sea.jpg

The home screen reads each with Image.asset and pubspec.yaml lists the asset directory. They display with no internet connection. For the final tourism app replace with authentic photos with proper permission and credits, using the same filenames. The rest of the app may still load remote images; only the home screen was changed.
